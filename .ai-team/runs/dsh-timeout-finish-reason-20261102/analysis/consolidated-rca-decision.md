# Consolidated RCA & Decision: dsh-timeout-finish-reason-20261102

## 1. Первопричина (RCA)
- Ложное сообщение DeepSeek Harness «Output token limit reached» было вызвано отправкой `finish_reason="length"` мостом `agy-bridge` при срабатывании 1-часового таймаута хода (`AGY_TIMEOUT_S=3600.0`, факт [F-01], [F-02], [F-06]).
- Клиент DSH жестко транслирует `finish_reason="length"` в событие `turn/end` с причиной `reason.kind="max-tokens"`, по которому компонент `TurnMaxTokensItem` выводит баннер о достижении лимита выходных токенов (факты [F-03], [F-04], [F-05]).
- Сам лимит токенов генерации (65536) не превышался: генерация была прервана исключительно по времени.

## 2. Согласованное решение
- Принять Вариант V1: в `bridges/agy-bridge/server.py` сделать возвращаемый `finish_reason` при graceful timeout настраиваемым через переменную окружения `AGY_GRACEFUL_TIMEOUT_FINISH_REASON` и файл `dynamic_config.json`.
- Значение по умолчанию: `"stop"`.
- Допустимые значения: `"stop"` (для предотвращения ложных алертов в DSH и чистого завершения) и `"length"` (для строгого соответствия прежнему поведению при необходимости).
- Диагностическое предупреждение `[⚠️ Превышен лимит времени хода agy...]` сохраняется в тексте без изменений.

## 3. План реализации
1. Добавить хелпер `_graceful_finish_reason()` в `bridges/agy-bridge/server.py`.
2. Заменить строковый литерал `"length"` на вызов `_graceful_finish_reason()` в L6868 (JSON) и L7015 (SSE).
3. Обновить и расширить тесты в `tests/test_agy_bridge_resilience.py`.

## 4. Отклонённые варианты
- Вариант V2 (безусловный хардкод `"stop"`): отклонён из-за нарушения принципа Zero-Hardcode.
- Вариант V3 (вендоро-зависимый хак по User-Agent): отклонён из-за нарушения принципа независимости от вендоров.

## 5. Протокол ДО / ПОСЛЕ
- ДО: Таймаут в `agy-bridge` возвращает `finish_reason="length"`, DSH отображает баннер «Output token limit reached».
- ПОСЛЕ: Таймаут в `agy-bridge` по умолчанию возвращает `finish_reason="stop"`, текст ответа сохраняется с диагностическим префиксом, баннер в DSH не появляется.
