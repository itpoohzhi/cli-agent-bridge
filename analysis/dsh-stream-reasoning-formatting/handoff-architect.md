# Handoff-пакет Системного Аналитика для Архитектора

## 1. Контекст и архитектурные драйверы (Architecture Drivers)
1. **DRV-01 (Чёткое разделение строк и предотвращение склеивания текста):** Мост `bridges/agy-bridge` обязан обеспечить детерминированное разделение независимых шагов планировщика переносами строк `\n\n`. Не допускается конкатенация текста независимых шагов без пробелов или переводов строк [F-01, F-04].
2. **DRV-02 (Устранение ложных срабатываний арбитража и повторов префиксов):** Механизм `_ContentArbiter` обязан исключить циклическое дублирование префиксов `[гейт оркестрации: активен...` при несовпадении промежуточных снимков или отсутствии `step_index` в событиях stdout [F-03, F-06].
3. **DRV-03 (Изоляция фазы мышления и сервисных преамбул):** В агентном режиме (при наличии `tools`) сервисные статусы и преамбулы шагов с вызовами инструментов не должны ломать отображение блока размышлений в UI DeepSeek Harness [F-02, F-05, F-10].
4. **DRV-04 (Гарантия целостности финального ответа `result.response`):** Метод `reconcile_result` обязан гарантировать доставку полного итогового ответа клиенту даже при расхождении с промежуточными дельтами [F-08].
5. **DRV-05 (Универсальность и независимость от вендора):** Решение реализуется на собственном слое шлюза без модификации кода клиентских приложений [F-09].

## 2. Требования (Requirements)
- **REQ-01 (Детерминированные границы шагов):** При включенном `planner_content_streaming_enabled` каждый новый шаг `(turn_id, cid, step_idx)` при передаче в поток контента отделяется от предыдущего текста разделителем `\n\n`, если предыдущий буфер не оканчивался переводом строки.
- **REQ-02 (Безопасный сканер префиксов в арбитре):** В `_ContentArbiter._scan` проверка кандидатов не должна сопоставлять короткие префиксы нового шага с длинными текстами завершённых шагов, вызывая ложную заморозку `step.frozen = True`.
- **REQ-03 (Поддержка изоляции сервисных преамбул в reasoning):** Предусмотреть конфигурируемую маршрутизацию сервисных преамбул шагов с `tool_calls` в `choices[0].delta.reasoning_content` (либо явное форматирование статусов в отдельный блок), чтобы предотвратить схлопывание блока мышления в UI Harness.
- **REQ-04 (Полная обратная совместимость):** Сохранение прохождения всех существующих тестов `tests/test_agy_bridge_resilience.py`.
