# Open Questions — Открытые вопросы

- **OPEN-01 (МОЖНО ПРОДОЛЖИТЬ):** Нагрузка на слоты семафоров (`max_concurrent`) при длительных сессиях (риск B-17).
  - *Допущение:* В `~/.dsh/.env` и конфигах мостов значение `BRIDGE_MAX_PARALLEL_CALLS` / `max_concurrent` уже выставлено с достаточным запасом (128-512 слотов), поэтому увеличение времени удержания слотов для длинных запросов не вызовет насыщения пула в однопользовательском режиме.
- **OPEN-02 (МОЖНО ПРОДОЛЖИТЬ):** Порядок считывания env-переменных в мостах.
  - *Допущение:* Приоритет считывания: специфичная переменная моста (например, `AGY_BRIDGE_IDLE_TIMEOUT_S`) -> общая системная переменная `BRIDGE_IDLE_TIMEOUT_S` -> безопасное значение по умолчанию (300.0 с).
