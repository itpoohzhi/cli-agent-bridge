# Пакет передачи Архитектору (Handoff to Architect)

## 1. Рекомендация профиля
- **Рекомендуемый профиль:** **Profile A (Targeted / Focused)**.
- **Обоснование:** Требуется точечное системное устранение 3 корневых причин инцидента в `cli-agent-bridge` без переработки общей архитектуры шлюза, строго соблюдая архитектурный принцип универсальности шлюза (AGENTS.md).

## 2. Предметные задачи для Архитектора
1. **Синхронизация токенов авторизации в `_prepare_agy_home` (`bridges/agy-bridge/server.py`):**
   - Добавить в процедуру подготовки изолированного `$clean_home` синхронизацию актуальных файлов авторизации `~/.gemini/antigravity-cli/antigravity-oauth-token` и `~/.gemini/antigravity-cli/antigravity-account.json` (с проверкой размера/mtime), наряду с существующим `jetski-standalone-oauth-token`.
2. **Безопасная нормализация параметров командной строки (`--print-timeout`):**
   - Обеспечить валидный формат единиц времени Go (`s`) при формировании аргумента `--print-timeout` в `bridges/agy-bridge/server.py:5392`, исключающий падение `agy.real` с ошибкой `missing unit in duration`.
3. **Универсальная устойчивость стриминга (Sliding Window & Keepalive):**
   - Гарантировать соблюдение инварианта *Sliding Activity Window* при чтении стрима из `agy.real` (продление дедлайна при получении полезных чанков, корректная обработка внезапного EOF/503 от локального прокси :10830).
4. **Универсальная нормализация имен моделей и каталогов (`core/http_post_routing.py`):**
   - В `_provider_allowed` и сопутствующей валидации моделей добавить устойчивость к суффиксам режимов/усилий (`-high`, `-low`) и сопоставление с каталогом опубликованных алиасов, исключающее ложный HTTP 404 `model is not in the catalogue`.

## 3. Критерии приемки архитектурного решения
- Соответствие `AGENTS.md` (никаких вендорских заплаток во внешних средах, все параметры конфигурируемы через ENV/конфиги, системные решения в ядре/мосте).
- Валидация Architecture Packet через `validate_architecture_packet.py`.
- Готовность спецификации для реализации сабагентом Coder.
