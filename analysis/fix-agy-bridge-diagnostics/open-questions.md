# Открытые вопросы (Open Questions)

## 1. Блокирующие вопросы (БЛОКЕР)
*Отсутствуют.* Все корневые причины локализованы непосредственно в исходном коде и конфигурациях стенда, блокеров для проектирования нет.

## 2. Неблокирующие вопросы (МОЖНО ПРОДОЛЖИТЬ)
- **Q-01 (Синхронизация токенов OAuth):** Нужно ли поддерживать двустороннюю синхронизацию или достаточно односторонней синхронизации свежего токена из `~/.gemini/antigravity-cli/` в `$clean_home` при каждом старте / перед вызовом CLI?
  - *Решение:* Односторонней синхронизации (копирование при несовпадении mtime/размера) достаточно, так как основной токен обновляется штатным клиентом Antigravity.
- **Q-02 (Таймаут хода и Sliding Window):** Каков оптимальный `idle_timeout` для шага стриминга?
  - *Решение:* Скользящее окно `idle_timeout_s = 60s` со сбросом дедлайна при получении каждого токена/чанка, с аварийным предохранителем `safety_cap_s = 600s` в соответствии с инвариантом L2 `AGENTS.md`.
- **Q-03 (Нормализация моделей в маршрутизаторе):** Как обрабатывать суффиксы усилий (`-high`, `-low`)?
  - *Решение:* Системно отсекать суффиксы усилий/режимов при поиске в каталоге провайдера, если точное совпадение не найдено, и использовать опубликованный alias-каталог.
