# Handoff для Архитектора: Устранение ложного срабатывания RepetitionGuard и стабилизация стрима

## 1. Входные требования и контекст
- **REQ-01:** Предотвратить ложные срабатывания `RepetitionGuard` на валидном тексте Markdown, содержащем списки инлайн-кода, разделённых пунктуацией (запятые, точки, тире, слэши).
- **REQ-02:** Обеспечить непрерывность SSE-потока при длительных шагах исполнения инструментов в `agy-bridge`, предотвращая обрыв соединения клиентом DeepSeek Harness (`Stream ended without finish_reason TRANSPORT`).

## 3. Открытые вопросы (Open Questions)
- `OPEN-01` (МОЖНО ПРОДОЛЖИТЬ): Токены, не содержащие буквенно-цифровых символов (пунктуация вроде `,` или `;`), не должны накапливать собственный счётчик повторений, но и не должны разрывать последовательность повторяющихся слов при конструкции `word , word , word`. Решение: не-алфавитные токены пропускаются при подсчёте повторов без сброса предыдущего словесного токена (`continue` без `prev = None`), либо изолированные знаки препинания исключаются из подсчёта `run`.
- `OPEN-02` (МОЖНО ПРОДОЛЖИТЬ): В стриминговом цикле `_execute` моста `agy-bridge` интервал отправки SSE-комментариев `: keepalive\n\n` составляет `KEEPALIVE_S = 15.0` с, что надёжно защищает HTTP-стрим от клиентского таймаута неактивности (60–120 с).

## 4. Предлагаемые архитектурные решения для фазы 2
1. **Ядро `core/tool_emulation.py`:**
   - В `RepetitionGuard._scan_cleaned`: изолированные токены без букв и цифр (`not any(c.isalnum() for c in token)`) не могут выступать в качестве повторяющегося токена (не инкрементируют `run` для самого себя), предотвращая ложные срабатывания на пунктуационных разделителях после очистки инлайн-кода.
   - В поиске периодических паттернов `tail`: исключать паттерны, у которых `core` состоит исключительно из не-буквенно-цифровых символов (`not any(c.isalnum() for c in core): continue`).
2. **Мост `bridges/agy-bridge/server.py`:**
   - Гарантировать регулярную отправку `: keepalive\n\n` с интервалом `KEEPALIVE_S = 15.0` с в ходе длительных шагов исполнения инструментов.
   - В `_ToolTurn` при возникновении `RepetitionLoopDetected` сохранять признак авторегрессионного зацикливания, чтобы в логах и диагностике разделять синтаксические ошибки вызова инструментов и зацикливание модели.
